🗺️ Как устроена система

Gramly — это два независимых инструмента, которые работают в одной экосистеме с единым входом через Telegram:

📤
AutoSending
Инструмент для автоматической Telegram-рассылки. Вы добавляете Telegram-аккаунты, задаёте каналы и шаблоны сообщений, запускаете кампанию — система рассылает самостоятельно с нужными задержками.
📊
CRM (GRAMLY)
Инструмент для ежедневного финансового учёта. Вносите данные по Cash Flow и заявкам — система автоматически считает итоги, формирует отчёты и уведомляет о пропущенных дедлайнах.
