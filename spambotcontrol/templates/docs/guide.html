AutoSending: быстрый старт

Полный цикл от первого входа до запущенной кампании. Пройдите шаги по порядку — это займёт около 10 минут.

💡
Перед началом
Вам понадобятся API credentials для каждого Telegram-аккаунта: api_id и api_hash. Их можно получить на my.telegram.org в разделе «API development tools».

1️⃣ Вход в систему

1
Откройте AutoSending
Перейдите по ссылке в боковом меню «AutoSending ↗» или напрямую на /spam/. Вас перенаправят на страницу входа.
2
Войдите через Telegram
Нажмите кнопку «Войти через Telegram». Telegram откроет окно подтверждения — нажмите «Confirm». Вход произойдёт автоматически.
3
Попадёте на Dashboard
Главная страница показывает статистику в реальном времени: активные аккаунты, запущенные кампании, число отправленных сообщений и живую ленту событий.

2️⃣ Добавление Telegram-аккаунтов

Аккаунты — это Telegram-профили, от имени которых будут отправляться сообщения. Добавьте хотя бы один перед созданием кампании.

1
Перейдите в раздел «Аккаунты»
В левом меню выберите «Аккаунты» → нажмите кнопку «Добавить аккаунт».
2
Введите API credentials
Заполните поля: api_id, api_hash и номер телефона (в формате +7...). Эти данные берутся из my.telegram.org.
3
Пройдите верификацию
Система отправит код подтверждения на указанный номер. Введите код — аккаунт перейдёт в статус active. Если включена двухфакторная аутентификация — введите пароль.
⚠️
Статус аккаунта важен
Только аккаунты со статусом active участвуют в кампаниях. Аккаунты в статусе pending или error отправлять сообщения не могут.

3️⃣ Добавление каналов

Каналы — это Telegram-каналы или чаты, в которые будут отправляться сообщения.

1
Перейдите в раздел «Каналы»
В левом меню выберите «Каналы» → нажмите «Добавить канал».
2
Введите ссылку на канал
Вставьте ссылку в формате https://t.me/channelname или @channelname. Система автоматически определит название канала и его ID.
3
Добавьте нужное количество каналов
Можно добавить любое число каналов. Один канал может использоваться сразу в нескольких кампаниях.

4️⃣ Создание шаблонов сообщений

Шаблоны — это тексты, которые будут отправляться в каналы. Система выбирает их случайно из прикреплённого к кампании набора.

1
Перейдите в раздел «Сообщения»
В левом меню выберите «Сообщения» → нажмите «Создать шаблон».
2
Напишите текст сообщения
Введите текст. Поддерживается обычный текст и базовое форматирование Telegram. Рекомендуется создавать несколько разных шаблонов — это снижает вероятность бана за одинаковые сообщения.
💡
Совет по шаблонам
Создайте 3–5 разных шаблонов с одним смыслом, но разными словами. Кампания будет автоматически чередовать их — это выглядит естественнее.

5️⃣ Создание и запуск кампании

Кампания объединяет аккаунты, каналы и шаблоны сообщений в один работающий процесс.

1
Перейдите в раздел «Кампании»
В левом меню выберите «Кампании» → нажмите «Создать кампанию».
2
Задайте параметры
Введите название, выберите аккаунты, каналы и шаблоны сообщений. Настройте задержку между сообщениями (минимум и максимум в секундах).
3
Запустите кампанию
Нажмите «Запустить» — кампания перейдёт в статус running. Аккаунты начнут отправку сообщений в указанные каналы с заданными задержками.
4
Следите за результатами на Dashboard
На главной странице в реальном времени обновляется счётчик отправленных сообщений и лента событий с каждым действием каждого аккаунта.
