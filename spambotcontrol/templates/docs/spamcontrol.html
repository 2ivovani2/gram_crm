Кампании и рассылки

Кампания — центральный объект AutoSending. Она связывает аккаунты, каналы и шаблоны сообщений в единый процесс рассылки. Здесь описано всё об управлении кампаниями.

🗂️ Как устроена кампания

👤
Аккаунты
Telegram-профили, от имени которых отправляются сообщения. У одной кампании может быть несколько аккаунтов — они работают параллельно.
📢
Каналы
Telegram-каналы или чаты назначения. Система перебирает каналы поочерёдно для каждого аккаунта.
💬
Шаблоны
Тексты сообщений. При каждой отправке система выбирает случайный шаблон из прикреплённого набора.
⏱️
Задержка
Диапазон паузы между отправками (в секундах). Случайное значение из диапазона min–max. Это защищает аккаунты от блокировки.

➕ Создание кампании

1
Откройте раздел «Кампании»
В левом меню выберите «Кампании» → нажмите кнопку «Создать кампанию».
2
Заполните параметры
Название — произвольное, для вашего удобства.
Задержка мин/макс — рекомендуем 30–120 секунд. Слишком короткая задержка увеличивает риск блокировки аккаунта.
3
Выберите аккаунты, каналы и шаблоны
Из списков выберите нужные объекты. Каждый аккаунт и каждый канал могут быть в нескольких кампаниях одновременно.
4
Сохраните и запустите
После сохранения кампания будет в статусе idle. Нажмите «Запустить» — статус изменится на running и начнётся отправка.

🔄 Статусы кампании

СтатусЧто означаетДействие
idle Кампания создана, не запущена Нажмите «Запустить»
running Кампания активна — идёт отправка Нажмите «Остановить» для паузы
stopped Кампания остановлена вручную Можно запустить снова

📊 Мониторинг в реальном времени

Dashboard отображает статистику и ленту событий с задержкой в несколько секунд:

📈
Счётчики
Число активных аккаунтов, запущенных кампаний и суммарное количество отправленных сообщений за всё время.
⚡
График активности
График успешных отправок по времени — показывает интенсивность работы кампаний.
📋
Лента событий
Каждое действие каждого аккаунта: вступление в канал, отправка сообщения, ошибка — с временем и деталями.

⚠️ Управление ошибками

В ленте событий на Dashboard ошибки подсвечиваются красным. Наиболее частые причины:

ОшибкаПричинаЧто делать
FloodWaitError Telegram требует паузу — слишком частые отправки Увеличьте задержку в настройках кампании
UserBannedInChannel Аккаунт забанен в конкретном канале Уберите канал из списка или замените аккаунт
SessionExpired Сессия аккаунта устарела — нужна повторная верификация В разделе «Аккаунты» пройдите верификацию повторно
AccountBanned Аккаунт заблокирован Telegram Удалите аккаунт из кампании, добавьте новый
💡
Рекомендованные настройки задержки
Для комфортной долгосрочной работы: задержка 60–180 секунд, не более 1–2 аккаунтов на канал в одной кампании. Это существенно увеличивает срок жизни аккаунтов.

✏️ Редактирование кампании

Кампанию можно редактировать в любой момент — даже во время работы. Изменения применятся при следующем цикле отправки:

  • Добавить или убрать аккаунты из кампании
  • Добавить или убрать каналы
  • Добавить или убрать шаблоны сообщений
  • Изменить задержку
⚠️
Удаление кампании
При удалении кампании удаляются её настройки, но не сами аккаунты, каналы и шаблоны — они продолжают существовать как независимые объекты.
