# GramlyView: проверка сценариев Trustat

Проверка проведена в Telegram Web с аккаунтом, у которого Trustat показывал Premium до 26.10.2026. Это сравнение пользовательских сценариев, не формул или оформления чужого продукта.

| Проверенный сценарий Trustat | Сценарий GramlyView | Источник данных | Состояние |
| --- | --- | --- | --- |
| Один публичный канал → текстовая карточка | Карточка с подписчиками, постами за 24/48/72 ч и ER24 | Bot API для подписчиков; разрешённые MTProto-замеры просмотров | Реализовано; формула GramlyView указана в отчёте |
| Несколько публичных каналов → текст сети и PNG сразу следом | До 20 ссылок из текста, подписи и скрытых `text_link`; сводка с покрытием, детали по кнопке | Те же источники для каждого канала | Реализовано; частичные результаты и ошибки независимы |
| «Статистика картинкой» → история и PNG | Одиночная карточка либо картинка сети | Снимки подписчиков и просмотров | Реализовано |
| Переключатели картинки: подписчики, рост, просмотры, ER, упоминания | Редактирование той же картинки inline-кнопками | Снимки; опциональные упоминания только из отслеживаемых публичных каналов | Реализовано; показывается покрытие, отсутствие данных не равно нулю |
| Коллекции и избранное | Сохранение каналов, анализ коллекции, корректный выход из ввода | GramlyView DB | Реализовано |
| Глобальный топ по просмотрам, пересылкам, комментариям, реакциям | Топ измеренных постов доступных пользователю каналов | MTProto-замеры за 7 дней | Реализовано; старые записи без новых полей не реконструируются |
| Мониторинг упоминаний | Подписка в карточке публичного канала и уведомление о новых упоминаниях | Посты уже индексируемых публичных каналов | Реализовано в ограниченном корпусе; это не поиск по всему Telegram |
| Калькулятор рекламы | Пользователь задаёт CPM; бот показывает формулу и оценку | Средние текущие просмотры постов за сутки | Реализовано без заявления о рыночной цене |
| Приватные приглашения | Анализ при наличии доступа разрешённого аккаунта | MTProto | Ограничено правами и состоянием приглашения; Trustat также не подтвердил универсальную поддержку |

**Методика GramlyView.** Основные 24/48/72 ч — средние текущие просмотры постов, опубликованных за соответствующий период, с числом постов и временем свежего сбора. ER24 — среднее по постам за сутки, делённое на актуальное число подписчиков. Точные просмотры к возрасту поста 24/48/72 ч остаются вторичным показателем: для него берётся первый фактический замер в двухчасовом окне после границы. Без подходящих данных выводится «нет данных»; прошлые просмотры не восстанавливаются. Формула Trustat TruViews не раскрыта, точного совпадения цифр не заявляем.

**Непроверенное в Trustat.** Личный пересланный список с 14 скрытыми ссылками ему не отправляли. Premium-иконки по Telegram Web не удалось подтвердить как custom emoji. Точные правила мониторинга и приватных приглашений остаются непроверенными; GramlyView не использует Trustat API и не вводит платный тариф.
