# GramlyView: проверка сценариев Trustat

Проверка проведена в Telegram Web с аккаунтом, у которого Trustat показывал Premium до 26.10.2026. Это сравнение пользовательских сценариев, не формул или оформления чужого продукта.

| Проверенный сценарий Trustat | Сценарий GramlyView | Источник данных | Состояние |
| --- | --- | --- | --- |
| Один публичный канал → текстовая карточка | Карточка с подписчиками, 24/48/72 ч и ER24 | Bot API для подписчиков; разрешённые MTProto-замеры просмотров | Реализовано; окна считаются по описанной ниже методике |
| Несколько публичных каналов → отдельные карточки, сводка, общая PNG | До 20 ссылок из текста, подписи и скрытых `text_link`; частичные результаты | Те же источники для каждого канала | Реализовано; реакция Trustat на 14 ссылок не проверялась |
| «Статистика картинкой» → история и PNG | Одиночная карточка либо картинка сети | Снимки подписчиков и просмотров | Реализовано |
| Переключатели картинки: подписчики, рост, просмотры, ER, упоминания | Редактирование той же картинки inline-кнопками | Снимки; для упоминаний пока нет подтверждённого источника | Реализовано; неизвестные значения указаны как «нет данных» |
| Коллекции и избранное | Сохранение каналов, анализ коллекции, корректный выход из ввода | GramlyView DB | Реализовано |
| Глобальный топ по просмотрам, пересылкам, комментариям, реакциям | Топ измеренных постов доступных пользователю каналов | MTProto-замеры за 7 дней | Реализовано; старые записи без новых полей не реконструируются |
| Вход в отдельный бот мониторинга | Добровольная ежедневная сводка в GramlyView | Снимки каналов | Аналогичная польза, собственный упрощённый сценарий |
| Приватные приглашения | Анализ при наличии доступа разрешённого аккаунта | MTProto | Ограничено правами и состоянием приглашения; Trustat также не подтвердил универсальную поддержку |

**Методика GramlyView.** Для каждого поста берём первый фактический замер в интервале от возраста 24/48/72 часа до ещё двух часов и усредняем просмотры по постам с таким замером. ER24 — среднее за 24 часа, делённое на актуальное число подписчиков. Число постов показано рядом с результатом. Без подходящего замера выводится «нет данных», исторические просмотры не восстанавливаются. Trustat называет свои показатели TruViews, но не раскрывает формулу; точное совпадение цифр не заявляется.

**Непроверенное в Trustat.** Личный пересланный список с 14 скрытыми ссылками ему не отправляли. Premium-иконки по Telegram Web не удалось подтвердить как custom emoji. Точные правила мониторинга и приватных приглашений остаются непроверенными; GramlyView не использует Trustat API и не вводит платный тариф.
